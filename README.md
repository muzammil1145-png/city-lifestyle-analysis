# 🌆 City Lifestyle Analytics Project
A data analytics project focused on exploring city lifestyle patterns, demographics, cost of living, transportation, and quality-of-life indicators using Python and data visualization techniques.

## 📌 Project Overview
This project analyzes urban lifestyle data to uncover trends and insights related to:
- Cost of living
- Housing affordability
- Transportation accessibility
- Population demographics
- Crime and safety metrics
- Lifestyle & livability indicators

The notebook demonstrates a complete analytics workflow including:
- Data cleaning
- Exploratory Data Analysis (EDA)
- Statistical analysis
- Data visualization
- KMeans Clustering
- PCA Analysis
- Insight generation

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 📊 Key Features
✔️ **Data Cleaning**
- Handled missing values
- Removed duplicates
- Standardized columns

✔️ **Exploratory Data Analysis**
- Distribution analysis
- Correlation analysis
- Outlier detection

✔️ **Data Visualization**
- Heatmaps
- Bar charts
- Scatter plots
- Trend visualizations

✔️ **Cluster Analysis**

Implemented K-Means Clustering to segment cities based on lifestyle and economic indicators.

The clustering model grouped cities using variables such as:
- Income levels
- Housing costs
- Transportation scores
- Population density
- Quality-of-life metrics

## 🔍 Clustering Methodology
1. Selected relevant numerical features
2. Standardized data for clustering
3. Applied K-Means clustering
4. Used the Elbow Method to determine optimal clusters

## 📈 Cluster Insights
🟢 **Cluster 1 – Affordable Cities**
- Lower cost of living
- Balanced lifestyle metrics
- Moderate population density

🔵 **Cluster 2 – High-Income Urban Areas**
- Higher salaries
- Expensive housing markets
- Strong economic activity

🟣 **Cluster 3 – Emerging Growth Cities**
- Developing infrastructure
- Moderate affordability
- Improving quality-of-life indicators
